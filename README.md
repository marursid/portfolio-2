1. **Interactive Reticle Cursor & Crosshair Targeting**: Dynamic precision cursor with live coordinate calculations and reactive hover states.
2. **3D Skull & Brain Specimen (Three.js & WebGL)**: Fully interactive 3D model with custom shader bloom, kinetic rotation, and organ mapping.
3. **Reactive Dialogue System**: The specimen whispers reactive lines when approached with the dissection tool (`"Please, don't do it."`, `"I'm awake, you know."`, `"I can feel that."`).
4. **Interactive Brain Dissection (GSAP ScrollTrigger)**:
   - **Node 1 (Primary Tissue)**: JavaScript (ES6+)
   - **Node 2 (Pituitary Gland)**: HTML5 & Semantic Web
   - **Node 3 (Motor System)**: GSAP & Creative Animation
   - **Node 4 (Vestibular System)**: Tailwind CSS & Responsive Layout
   - **Node 5 (Association Cortex)**: React.js
   - **Node 6 (Peripheral System)**: TypeScript
   - **Node 7 (Meninges)**: Git & Version Control
5. **Real-time Vitals Telemetry**: ECG heart rate monitor waveform with pulsing dot and live biometric readouts (`SpO₂`, `EtCO₂`, `HR`).
6. **Synthesized Sci-Fi Sound FX**: Web Audio API audio synthesis toggled with `"ENABLE SOUND"` / `"DISABLE SOUND"` (blips, heartbeat pulses, incisions, gear clicks).

## 🚀 How to Run Locally

### Option 1: Node Server (Included)
```bash
npm start
# or
node serve.js
```
Open [http://localhost:3000](http://localhost:3000) in your web browser.

### Option 2: Any Static HTTP Server
```bash
npx serve .
# or
python -m http.server 3000
```
